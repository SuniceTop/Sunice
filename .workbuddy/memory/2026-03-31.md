# 2026-03-31

## 创建 @chenglou/pretext Demo

- 项目已安装 `@chenglou/pretext@0.0.3`，使用 bun 作为构建工具
- 创建了 `pretext-demo.html` 和 `pretext-demo.js` 两个文件
- Demo 包含三个功能演示：
  1. **文本高度预测器**：输入文字 + 调节宽度/行高，`layout()` 零 DOM 读取给出精确高度，与 `offsetHeight` 对照
  2. **聊天气泡收缩包裹**：用 `walkLineRanges()` + 二分法找最小气泡宽度，可调节最大宽度实时观察
  3. **Resize 热路径性能对比**：左侧 pretext（零 reflow），右侧 DOM offsetHeight（累计 reflow 计数器）
- 通过 `bun pretext-demo.html --host=127.0.0.1:3001` 启动开发服务器
- 核心 API：`prepare(text, font)` → 一次性预处理；`layout(prepared, maxWidth, lineHeight)` → 亚毫秒级布局计算
- 用户概念确认：pretext 不替代 DOM 渲染，而是替代"用 DOM 测量文字高度"这一步，渲染依然走 DOM，测量完全脱离 DOM

## Editorial Engine Demo（19:22）
- 新建 `editorial-engine.html` + `editorial-engine.js`，复刻官方 editorial-engine 示例
- 功能：5 个彩色发光球体在全屏飞行，正文文字实时环绕球体，多列排版，首字下沉，标题自适应字号

- 启动命令：`bun editorial-engine.html --host=127.0.0.1:3002`
